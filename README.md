# Metropolis Rogue (Vite + Vue 3)

A small turn-based, card-driven city builder rendered on an HTML canvas with Tailwind CSS styling. The project now uses Vite and Vue 3 for structure and reactivity.

## Scripts
- `npm run dev` — start the Vite dev server.
- `npm run build` — build for production.
- `npm run preview` — preview the production build.

Tailwind is loaded via CDN in `index.html`, and the pixel-inspired font stack is defined in `src/style.css`.
